# Core dependency
# ---------------
# scapy handles packet capture, PCAP reading, and protocol dissection.
# Version 2.5.x is a stable branch compatible with Python 3.11+.
# On Linux, live capture requires root or CAP_NET_RAW.
# On Windows, Npcap (https://npcap.com) must be installed separately.
# On macOS, sudo is typically required for live capture.
#
# To verify your installed version:
#   python -c "import scapy; print(scapy.__version__)"
#
scapy>=2.5.0,<2.6.0
